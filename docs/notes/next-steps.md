# 다음 작업

## 기준

```txt
운영 데이터가 안정적인가
  → 기존 화면의 사용성이 완성되었는가
    → 그 다음에 새 기능을 추가한다
```

## 다음에 할 일

### 1. 영화 차트 월간 비교 검토

- 기존 `순위 흐름`과 목적이 다른 월간 비교 기능 검토
- 월별로 관객 수가 많았던 영화, 순위 변화, 기간 요약 표시
- 데이터가 충분한 달만 비교 대상으로 표시
- 월간 비교를 추가하더라도 로비에 별도 큰 카드를 만들지 않음

### 2. MY CINEMA 구조 검토

- 관람 기록·찜·엽서·통계를 한 화면에 계속 보여줄지 확인
- 화면이 길어지면 Radix Tabs로 영역 분리
- 모바일에서 탭 이동과 현재 위치 표시 확인

### 3. 지역별 영화관 탐색

- 완료: Region 선택 후 해당 Region의 영화관 전체 조회
- 완료: 카카오 Local 검색 결과를 Cinema DB에 저장
- 완료: Leaflet Marker와 영화관 목록 연결
- 완료: 카카오맵·네이버지도·Google Maps 외부 길찾기 링크 연결
- 다음: 구·군 선택과 행정구역 경계 표시를 별도 기능으로 검토
- 구현 기준은 [영화관 지도](../lobby/cinema-map.md)에서 관리

### 4. Admin 재설계

- Admin 전체 메뉴와 화면 구조 확정
- 필요한 통계와 필터 확정
- API 응답 형태 안정화
- 마지막에 Excel·CSV 내보내기 검토

### 5. 사용자 관람 통계

- 많이 본 감독·장르·관람 월 집계
- 관람 장소별 통계
- 연말 요약 화면에서 재미있게 보여줄 수 있는 항목 선별

### 6. 재개봉일 데이터 보강

- TMDB·KOBIS에 재개봉일이 없으면 MovieChart의 `개봉일 확인 중` 상태로 유지
- MovieChart 오류로 단정하지 않고 외부 데이터 부족 상태로 기록
- 나중에 공식 극장·배급사 정보 크롤링 또는 관리자 보정 기능 검토

## 현재 결정

- 로비에는 `이번 달 흐름 요약` 별도 카드를 추가하지 않음
- 로비의 `MOVIE CHART` 카드에서 오늘의 순위와 이번 달 흐름을 함께 안내함
- 상세 월간 데이터는 `/moviechart`에서 제공함
- MovieChart 상위 탭은 URL query와 동기화하고 `router.replace`와 `scroll: false`를 사용함
- `Box Office Now`와 월간 요약의 현재 순위·관객 수를 중복 표시하지 않음
- Admin Excel 기능은 구조와 API가 정리된 뒤 마지막에 검토함
- 카카오 로그인은 사업자 인증 전까지 추가하지 않음
